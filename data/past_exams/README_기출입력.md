# 기출 문항 입력 방법

단원마다 CSV 파일 하나를 만든다. 파일 이름은 단원 폴더 이름과 같게 한다 (예: `I-2_화학_변화.csv`). `TEMPLATE.csv` 를 복사해서 쓰고, 예시 행은 지운다. 엑셀로 편집해도 되지만 저장은 CSV UTF-8 로 한다.

| 열 | 뜻 | 적는 법 |
|---|---|---|
| school | 출처 학교 | 짧은 이름. 여러 학교 자료를 모을 때 학교별로 나눠 보는 데 쓴다 |
| id | 문항 식별자 | 아무 문자열 |
| year | 출제 연도 | 숫자 |
| section | 소단원 | `units.json` 의 소단원 이름 그대로 |
| objective_id | 학습목표 id | `data/objectives/<단원>.json` 의 id. 모르면 비운다 |
| format | 문항 형식 | `개념 확인`, `자료 해석`, `계산`, `서술형`, `탐구 설계` 중 하나. 비우면 규칙으로 자동 분류 |
| stem | 발문 | 표나 그림은 글로 풀어 쓴다 |
| options | 보기 | ` \| ` (세로줄)로 구분. 서술형은 비운다 |
| answer | 정답 | 객관식은 번호, 서술형은 모범답안 요지 |

공개된 자료만 쓰고, 문항 원문을 저장소에 올리지 않는다.
